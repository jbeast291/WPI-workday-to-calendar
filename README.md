# WPI Workday to Calendar

Convert your WPI Workday schedule export (`.xlsx`) to an iCal file (`.ics`) that you can import into Google Calendar, Apple Calendar, Outlook, or any other calendar app.

> [!WARNING]
> Always double-check your exported calendar for inaccuracies. This tool provides no warranty (See [LICENSE](LICENSE) for details.).

**🌐 [Use the tool online →](https://jamubc.github.io/UBC-workday-to-calendar/)**
